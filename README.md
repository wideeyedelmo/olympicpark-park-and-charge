## 구성
- `analysis/pipeline.py` : 분석 코드 (정제 → 체류시간 → 동시 주차 → 판정 → 시나리오)
- `data/` : 집계 결과
  - `summary.json` 대시보드·리포트가 읽는 집계값
  - `dwell_hist.csv` 체류시간·급속 충전시간 분포(10분 구간, %)
  - `hourly_occupancy.csv` 평일·주말 시간대별 평균 동시 주차대수
  - `scenarios.csv` 전기차 비율·충전 희망 비율별 필요 완속 수, 급속 수요 시간
- `index.html` : 정적 웹 대시보드 (GitHub Pages로 공개)
- `figures/` : 근거 그래프 이미지
- `report/올림픽공원_충전기_배치_권고_리포트.pdf` : 배치 권고 리포트
- `report/make_report.py` : 리포트 생성 코드

## 실행
```
pip install pandas numpy
python analysis/pipeline.py --parking 입출차.csv --charging 합성데이터.zip --congestion 혼잡도.csv --out data
```

## 2025년 구역별 데이터 반영 방법
1. 문화공공데이터광장에서 `올림픽공원 입출차정보(전체구역)` API를 활용신청해 받습니다.
2. 결과를 `입차일시, 출차일시, 주차구역` 컬럼의 CSV로 저장합니다.
3. 위 명령의 `--parking`에 그 CSV를 넣으면 `zone_summary.csv`와 `summary.json`의 `zones`가 생성됩니다.
4. 대시보드의 구역별 권장안 표가 그 값을 쓰도록 연결합니다.

## 정제·판정 기준
- 체류 10분 미만: 통과·회차 차량으로 제외 / 3일 이상: 장기주차로 제외
- 급속형 < 42분 <= 혼합형 < 102분 <= 완속형 (42분 = 급속 충전 90분위, 102분 = 42분 + 급속 방치 허용 1시간)
- 필요 완속 = 기준일 완속형 최대 동시 주차 × 전기차 비율 × 충전 희망 비율
